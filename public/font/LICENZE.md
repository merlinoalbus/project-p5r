# Font predefiniti inclusi nell'app

Questi file sono i font liberi usati dall'interfaccia quando l'utente non ha caricato i propri
(Impostazioni → Caratteri). Sono sottoinsiemi «latin» in formato WOFF2 presi da Google Fonts.

| File | Famiglia | Ruolo nell'app | Licenza |
|---|---|---|---|
| `anton-latin.woff2` | Anton (The Anton Project Authors) | display: titoli, numeri grandi | SIL Open Font License 1.1 — `OFL-anton.txt` |
| `bebas-neue-latin.woff2` | Bebas Neue (Ryoichi Tsunekawa, Dharma Type) | menu: navigazione, pulsanti, etichette | SIL Open Font License 1.1 — `OFL-bebas-neue.txt` |
| `special-elite-latin.woff2` | Special Elite (Astigmatic) | decor: tasselli «ritaglio di giornale» | Apache License 2.0 — `LICENSE-special-elite.txt` |
| `inter-latin.woff2` | Inter (The Inter Project Authors) | corpo del testo | SIL Open Font License 1.1 — `OFL-inter.txt` |

I font della comunità ispirati a Persona 5 (P5 Hatty, Persona 5 Menu Font Prototype, Exposé) e i font
commerciali NON sono inclusi nel repository: l'utente li carica nella propria istanza, dove restano
(`DATA_DIR/font/`), nel rispetto delle rispettive licenze.
