### 3.3 Modifica precisa (back-end)

1. **Casa dei dedali** in `server/services/mappe/casaMappa.ts` (accanto a `casaDelPalazzo`, riga 69): due funzioni pure
   `casaDeiMemento = () => '/guida/dungeon/mementos'`,
   `casaDelDedalo = (dedalo: string, areaDedalo?: string) => '/guida/dungeon/mementos?area=' + encodeURIComponent(dedalo) + (areaDedalo ? '&zona=' + encodeURIComponent(areaDedalo) : '')`.
   Sono gli stessi indirizzi che `ombreService.ts:86-87` costruisce a mano (`?area=` per `tipo === 'mementos'`): fare usare la funzione anche lì è opzionale e spetta a L8 (non toccare `ombreService` da L11 senza accordo). `casaMappa.ts:74-81` è toccato anche da B9 (`entitaDellaRadice`): rileggere il file prima di modificarlo.
2. **Nodo Memento** in `gerarchiaMappe.ts` (funzione nuova, stesso stile delle altre, una lettura in blocco, nessuna query per nodo):
   ```sql
   -- dedali
   SELECT a.chiave, a.nome, a.ordine FROM dungeon_area a JOIN dungeon d ON d.chiave = a.dungeon_chiave
     WHERE d.tipo = 'mementos' ORDER BY a.ordine, a.chiave;
   -- aree dei dedali
   SELECT ad.chiave, ad.nome, ad.ordine, ad.dedalo_chiave FROM area_dedalo ad JOIN dungeon_area a ON a.chiave = ad.dedalo_chiave
     JOIN dungeon d ON d.chiave = a.dungeon_chiave WHERE d.tipo = 'mementos' ORDER BY a.ordine, ad.ordine, ad.chiave;
   -- conteggi per area: Persona distinte, Trame, Richieste
   SELECT area_dedalo_chiave, COUNT(DISTINCT voce_chiave) FROM persona_area_dedalo GROUP BY 1;
   SELECT area_dedalo_chiave, COUNT(*) FROM punto_interesse WHERE tipo = 'trama' AND area_dedalo_chiave IS NOT NULL GROUP BY 1;
   SELECT area_dedalo_chiave, COUNT(*) FROM richiesta WHERE area_dedalo_chiave IS NOT NULL GROUP BY 1;
   ```
   Nodi: **`memento`** (chiave `mementos`, nome dal `dungeon.nome` = «Memento», `casa = casaDeiMemento()`, `immagine: null` — il segno lo disegna il FE con `EmblemaDungeon`), figli **`dedalo`** (chiave = `dungeon_area.chiave`, `casa = casaDelDedalo(chiave)`, figli le aree), figli **`area-dedalo`** (chiave = `area_dedalo.chiave`, `casa = casaDelDedalo(dedalo, area)`, nessun figlio, nessuna planimetria). Un'area del dedalo **non ha planimetrie** (R11-11/3): il tipo `area-dedalo` non ha `figli`.
   Inserimento: `radici: [tokyo, ...(nodoMemento ? [nodoMemento] : []), nodoDaCollocare]` (riga 198). **Memento radice accanto a Tokyo** è la regola E8 già decisa (`L11/modifiche.md:139-142`) e il default di B5 (`B5-albero.md` D8b); la memoria di progetto dice invece «Città → Memento» (D1 sotto).
