## 3. B12 — Frasi e copie (R11-02/9, R11-02/10, R11-02b/3, R11-02b/5)

### 3.1 Principio applicato (R6-18, R11-01)

Si toglie **solo** ciò che è copia esatta del dato strutturato **provata con una query**. Una frase che aggiunge contesto resta una nota: se qualcuno la legge (a schermo o in un editor) la colonna resta; se non la legge nessuno la si **archivia** nel DB (blocco `dati_guida` `archivio-frasi-l11`, «di archivio» con motivo, come le bonifiche di L5–L7: BON-06) e poi si toglie la colonna. Questo evita la scelta falsa «perdo la frase / tengo una colonna invisibile». Si toglie con `ALTER TABLE … DROP COLUMN` (SQLite 3.53.2 in `node_modules`, precedenti `089_dote_a_ogni_incontro_riparata.ts:48`, `099_aree_dei_dedali.ts:62`): per tutte le colonne di questa scheda non esistono indici, trigger, viste né `CHECK` che le citino (controllato sulla copia a v146: 0 viste, 0 indici/trigger che le nominano).
