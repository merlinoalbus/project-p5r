## Principi di design dichiarati dagli autori
✔ https://personacentral.com/persona-5-panel-concept-development-ui/ — panel CEDEC 2017 di Masayoshi Sutoh (art director/lead UI):
rosso "passionale" come unico colore guida, nessun sotto-colore; leggibilità affidata a bianco e nero; concept "pop punk";
font "che ballano", layout a griglia irregolare; ordine di lavoro colore → logo → font; UI 3D nata da layout Photoshop.
- ✔ https://personacentral.com/wp-content/uploads/2017/11/Persona-5-Prototype-UI-01.jpg — layout Photoshop del menu principale (MAIN / SKILL / ITEM / SYSTEM).
- ✔ https://personacentral.com/wp-content/uploads/2017/11/Persona-5-UI-Slide-03.jpg — slide "Pop punk", battaglia "1 MORE".
